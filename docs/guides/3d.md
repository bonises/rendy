# 3D rendering

rendy's 3D layer is a forward PBR renderer: HDR, 4× MSAA, cascaded + cube
shadow maps, tonemapping, bindless materials. You describe a `Scene`, point
a `Camera` at it, and draw:

```cpp
Scene scene(app);
scene.setAmbient(Color::rgb(0x1A1C22));

auto sun = scene.addLight({.type = Light::Type::Directional,
                           .direction = {-1, -2, -1},
                           .intensity = 3.0f,
                           .castsShadows = true});
scene.addMesh(primitives::plane({20, 20}), scene.defaultMaterial());
auto helmet = scene.loadGltf("DamagedHelmet.glb").value();

Camera camera;
camera.lookAt({3, 2, 3}, {0, 0.8f, 0});

while (app.pollEvents()) {
    scene.node(helmet).rotateY(app.dt());
    auto frame = app.beginFrame({});
    frame.draw(scene, camera);      // shadows → PBR pass → tonemap
    // canvas draws land on top — perfect for HUDs
    frame.present();
}
```

## Scene & nodes

The scene is a flat array of nodes addressed by `NodeId` — no scene-graph
classes. A node has a `Transform` (position/rotation/scale), optionally a
parent, and optionally a mesh+material or a light. Mutate via the proxy:

```cpp
scene.node(id).setPosition({0, 1, 0}).rotateY(0.02f).setScale(2.0f);
Transform& t = scene.transform(id);       // direct access
scene.setParent(child, parent);           // hierarchy when you need it
scene.removeNode(id);                     // removes the subtree
```

## Meshes

- **Primitives**: `primitives::cube/sphere/plane/cylinder/cone/capsule/torus`
  return `MeshData` (positions, normals, tangents, UVs) — tweak or upload
  as-is with `scene.addMesh(data, material)`.
- **Custom**: fill `MeshData` yourself; indices are `uint32_t` triangles.
  Reuse geometry with `createMesh` once + `addMesh(handle, ...)` many times.
  `destroyMesh(handle)` frees the GPU space for reuse (nodes still using
  the mesh stop drawing, with a warning). Handles are generational: a stale
  handle kept after `destroyMesh` stays inert even when its id is recycled.
- **glTF 2.0**: `scene.loadGltf("model.glb")` imports meshes, PBR
  materials, textures (correct sRGB/linear handling), the node hierarchy,
  **skins, animations and morph targets**; returns the root `NodeId`.
  Missing normals/tangents are generated. Supported extensions:
  **KHR_draco_mesh_compression** (compressed geometry, decoded on load),
  **KHR_texture_basisu** (KTX2 textures — ETC1S/UASTC transcoded to BC7,
  full mip chain, stays compressed on the GPU; devices without BC support
  fall back to RGBA32), KHR_mesh_quantization and
  KHR_materials_emissive_strength. One caveat: morph targets on a
  draco-compressed primitive are skipped (draco reorders vertices). Other
  KHR material extensions are not imported yet.

## Animation

Clips from glTF files register on the scene:

```cpp
auto fox = scene.loadGltf("Fox.glb").value();
scene.playAnimation("Run");            // or by AnimationHandle
while (app.pollEvents()) {
    scene.updateAnimations(app.dt());  // advances clips → node transforms
    ...
}
```

- `animationNames()` lists loaded clips; `findAnimation(name)` gives a
  handle; `playAnimation(handle, loop, speed)`, `stopAnimation`,
  `stopAllAnimations`, `animationPlaying`.
- **Blending**: several clips can play at once — samples blend per node
  (`setAnimationWeight`). Weights above 1 normalize; when a channel's total
  weight is below 1 the remainder blends toward the node's authored base
  pose, so a fading clip eases back instead of freezing — even for channels
  the incoming clip doesn't animate. To switch clips smoothly, use
  `crossfadeAnimation(to, fadeSeconds)`: the new clip fades in while every
  other playing clip fades out and stops. Quaternions blend
  hemisphere-safely.
- Channels animate node translation/rotation/scale with step, linear
  (slerp for rotations) or cubic-spline interpolation.
- **Skinning** is automatic: skinned meshes follow their skeleton (joint
  matrices are computed per frame and applied in the vertex shader, shadows
  included). Characters from Mixamo/Blender exported as glTF work directly.
- **Morph targets** (shape keys) work too: position/normal deltas apply in
  the vertex shader, glTF weight animations drive them, and
  `scene.setMorphWeights(node, {...})` gives procedural control (facial
  rigs, sliders). TANGENT deltas are ignored, so normal-mapped surfaces can
  shade slightly off under extreme morphs.
- `scene.approximateRadius(root)` helps frame a camera around a model of
  unknown scale (see `05_model_viewer`, which also cycles clips with A).

## Materials

PBR metallic-roughness, exactly glTF's model:

```cpp
auto gold = scene.createMaterial({
    .baseColor = Color::rgb(0xFFD700),
    .metallic = 1.0f,
    .roughness = 0.25f,
    // optional textures (load with app.loadTexture; use .srgb=false for
    // normal/metallicRoughness/occlusion maps, .mipmaps=true for all):
    // .baseColorTexture, .metallicRoughnessTexture (G=rough, B=metal),
    // .normalTexture, .occlusionTexture, .emissiveTexture
});
```

Factors multiply textures. `emissive` glows (it survives tonemapping
nicely — use intensities > 1 via `Color` values times alpha).

Alpha: set `.alphaMode` — `Opaque` (default), `Mask` (discard below
`.alphaCutoff`; foliage/fences, still writes depth and shadows), or `Blend`
(glass/effects: alpha-blended back-to-front after the opaque pass, no depth
write, doesn't cast shadows). glTF alphaMode maps automatically.

## Environment (skybox + IBL)

```cpp
scene.setEnvironment("sky.hdr").value();   // equirectangular HDR (Poly Haven etc)
scene.setEnvironmentIntensity(1.2f);
scene.clearEnvironment();                  // back to flat ambient
```

Setting an environment gives you a skybox background **and** image-based
lighting: diffuse irradiance replaces the flat ambient and rough-to-mirror
specular reflections come from a GGX-prefiltered cubemap (split-sum with a
BRDF LUT). Baking happens once at load (~tens of ms). Grab free CC0 HDRIs
from polyhaven.com/hdris.

## Reflection probes (local reflections)

The global environment reflects the *sky* — indoors you want surfaces to
reflect the *room*. Add up to 8 local probes:

```cpp
scene.addReflectionProbe({.position = roomCenter,           // capture point
                          .boxMin = roomCenter - Vec3{3, 2, 4},
                          .boxMax = roomCenter + Vec3{3, 2, 4},
                          .fade = 0.5f});                    // edge fade (world units)
scene.bakeReflectionProbes();  // after scene setup — blocking, ~ms per probe
```

Each bake renders the scene (opaque + skybox; transparents are skipped) from
the probe position into a 128² cubemap and GGX-prefilters it. Fragments
inside the box use the probe for specular reflections with **parallax
correction**: the reflection ray is intersected with the box, so reflections
stick to the walls instead of floating at infinity. Diffuse ambient still
comes from the global environment/flat ambient. Overlapping probes pick the
one with the strongest edge-fade weight; near the box edge the probe blends
back into the global environment over `fade` world units.

Probes are static captures — re-call `bakeReflectionProbes()` when static
geometry or lighting changes (it re-captures every alive probe). Works with
or without an HDRI environment. The probe cubemap storage is app-global:
the most recently baked `Scene` owns it, so with multiple scenes only the
last-baked one gets probe reflections until the others bake again. See the
mirror-sphere alcove in `04_scene3d`.

## Lights & shadows

| Type | Position/direction | Falloff | Shadows |
|---|---|---|---|
| `Directional` | `direction` | none | 4-cascade CSM, PCF |
| `Point` | `position` + `range` | inverse-square, windowed to range | cube map (up to 4 casters) |
| `Spot` | both + `innerCone`/`outerCone` | same + cone | 2D map (up to 8 casters) |

Set `.castsShadows = true` per light. One directional light can cast at a
time. Lighting is **clustered forward+**: point/spot lights are binned into
a 16×9×24 view-frustum grid each frame and each pixel only shades its
cluster's lights — a thousand small lights runs fine (set `.range` so
lights stay local; unbounded lights hit every cluster). Intensity is linear
radiometric-ish: directional ~1–5, point/spot ~5–50 depending on range.

## Camera

`Camera` is a struct: `position`, `rotation` (or `lookAt(eye, target)`),
`fovY`, `nearPlane`, `farPlane`. Build orbit/fly controllers in user code —
see `04_scene3d` and `05_model_viewer`.

## What happens per frame

1. Shadow passes render every mesh into the shadow atlases (depth only).
2. The scene pass draws frustum-culled meshes into an HDR (RGBA16F) 4× MSAA
   target; nodes sharing a mesh+material render as one instanced draw, and
   all textures are bindless, so material changes never rebind descriptors.
   Reuse geometry via `createMesh` once + `addMesh(handle, ...)` many times
   to benefit.
3. The skybox draws at far depth, then MSAA resolves and a tonemap pass
   (Khronos PBR Neutral by default, ACES optional) writes the swapchain.
4. The 2D canvas paints on top.

Conventions: y-up, right-handed, -z forward (glTF-compatible), depth 0..1.
Triangles are counter-clockwise seen from outside; back faces are culled.
